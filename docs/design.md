# ZAK — 기획 결정사항 정리 v2 (2026-08-05)

> docs/design.md를 대체하는 전면 개정판. [확정] / [유력] / [미결]로 구분.
> 유력 = 방향은 합의됐으나 플레이 검증 전. 미결 = 결정 대기.

## 1. 컨셉 [확정]

대한민국 실제 지도(부산에서 시작) 위의 포스트 아포칼립스 생존 스캐빈징 게임.
핵심 재미: **"길거리를 돌아다니다 '저기 뭔가 있을 것 같다!' 싶은 건물을 발견해 들어가는 것."**
진입을 제한하는 4대 제약: 낮 시간, 스태미너, 인벤토리 한계, 필요 물품의 명확성.

- 참조점: 배그/타르코프(루팅 긴장), 다크우드(탑뷰+시야 공포), Project Zomboid(자유 거점), 미니 모토웨이(미학), 다키스트 던전(긴장/이완 리듬, 스트레스)
- 전염병주식회사류 수치 시뮬레이션 게임성은 서브로만 (메인이면 재미없음)

## 2. 게임의 등뼈: 시야 = 성장 [확정]

줌 6단계는 처음부터 주어지는 게 아니라 **벌어서 얻는 능력**이다.

| 성장 단계 | 열리는 시야 | 수단 |
|---|---|---|
| 초반 | 1~2단계 (내 몸: 전방 120도, 500m) | 걸어서 밝힘 (스타크래프트식 탐사 기억) |
| 중반 | 3~4단계 | 드론 획득 (전경은 보이나 상세는 직접 방문 필요) |
| 후반 | 5~6단계 | 관제 능력: 거점, 동료 원거리 지원, 비동기 정보 |

- LOS(가림) 처리: 일단 없이 테스트 → 필요 시 추가 [유력]
- 건물 상세정보는 한번 보면 해금되어 원거리 열람 가능 (개연성 = 드론) [유력]

## 3. 하루 루프 [확정]

**낮 = 긴장, 밤 = 이완.** 긴장 루틴이 끊임없이 이어지면 안 된다.

- 낮: 맵을 보고 목적지 탐색 → 신속 이동 → 주의 깊은 파밍 → 일몰 전 안전구역 확보
  - 긴장의 두 축 [유력]: **일몰 = 자기장** (멈출 수 없고 눈에 보이는 시간 압박), **소지품 = 판돈** (안전구역에서 밤을 보내야 획득 확정 — 타르코프식)
  - 위협: 어두운 장소의 좀비, 다른 스캐빈저(NPC/비동기 유저 흔적 — 건물 창의 손전등 불빛 등으로 표시) [유력]
- 밤: 안전구역에서 정비 (음식 섭취, 아이템 정리, 내일 계획, 야경 감상). 아주 가끔만 특별 이벤트(밤 외출 임무, 조우)
- **텍스트 선택지("숨죽인다/확인한다" 류)는 최소화** — 1인 개발 텍스트 품질 한계 인식

## 4. 좀비 [확정]

- 어그로 조건부: 시야에 들어옴 / 소음 / 선공 시에만 추격 (무조건 추격 아님)
- 워킹데드식 단일 타입으로 시작 (구현·직관성). 변종은 추후 콘텐츠
- 밤 골목길 술래잡기: 실제 골목 데이터(대연동 등)가 추격전 레벨디자인이 됨

## 5. 파밍/루팅

- 건물 진입 → 층별 상점 정보(실데이터) 기반 수색 [확정, 구현됨]
- 층계 스태미너: 엘리베이터 불가, 오를 때 -5/층, 내릴 때 -1/층, 동선 뒤죽박죽 시 추가 소모 [유력]
- 루팅 UI: 배그식 리스트 드래그앤드롭 [확정 방향, 미구현]
- 잠긴 문/금고: 퍼즐 미니게임(손맛 계열: 락픽/배선/다이얼) + 키·비번 대체 루트 [유력 — 장르가 슈터로 가면 축소/제거 가능]
- 실내: 시야 제한(타르코프 참고), 건물 크기·형태·타입별 모듈/랜덤 생성 [유력, 별도 씬 프로토로 검증]
- 소음 게이지 시스템은 폐기. 소음은 특수 오브젝트(단단한 금고 등) 상호작용의 하이리스크 하이리턴용으로만 재검토

## 6. 아이템 [확정 방향]

- 원칙: **기능 원형은 소수(식량/회복/도구/연료/열쇠/무기/가치품), 가짓수는 다수** — 현실의 잡다한 물건은 무게+교환가치만 가진 가치품으로 흡수
- 크래프팅(재료 조합 제작)은 최소화 또는 제거
- 생존게임식 복잡함 거부. "심플하면서 깊이"

## 7. 안전구역 [유력]

- 자유 지정: 원하는 건물을 그날의 안전구역으로 (Project Zomboid 참고)
- 건물별 거점 적성: 층수, 출입구 수, 수색 완료율이 밤 안전도를 결정 → "좋은 집 찾기"가 파밍 판타지의 밤 버전이 됨
- 낮에 확인 안 한 층 = 밤의 리스크 (수색의 지연된 청구서)

## 8. 구역 정화와 불빛 [유력]

- **파밍 = 수단, 소탕 = 마침표, 불빛 = 보상**: 파밍으로 재료(연료/전력 부품 등)를 모아 구역의 어둠의 근원을 소탕+전력 복구하면 그 블록에 불이 들어옴
- 나와 다른 유저들이 지켜낸 구역은 밤에도 불 밝힌 활성 도시로 보임 — 진행도를 숫자가 아닌 도시의 빛으로 표현 [확정 의지]
- 비동기 멀티: 서버는 구역별 확보도만 공유 (가벼움)
- 정화 조건의 최종 확정은 [미결] (파밍만 vs 소탕 필수)

## 9. 캐릭터 자원 [유력]

- 기본: 체력 + 스태미너 (포만감은 "음식=스태미너 회복"으로 통합 검토)
- 다키스트 던전식 스트레스: 관심 있음. 밤 공포 연출이 자리 잡은 뒤 추가 검토
- 게이지 개수 절제 원칙 (2~3개 유지)

## 10. 비주얼 [구현 완료분]

- 원근 카메라 수직 탑뷰 + footprint×층수 extrude (가장자리 고층 기울어짐)
- 소팅 해결된 불투명 버텍스컬러 셰이더 (ZAK/BuildingUnlit)
- 높이 기반 팔레트 + 건물별 편차 (임시 — 추후 지도 앱 참고해 수동 팔레트)
- 야경 시스템: 점등률(Lit Ratio)/창문 점등률(Window Lit Ratio) 슬라이더, 프로시저럴 창문, 원거리 점광 LOD(카메라 높이 기준, 팬 미끄러짐 없음), 뷰폭별 감쇠(10km 이하 -60% ~ 25km -30%), 블룸(Post Processing)
- 밤: 건물·도로 모두 어둠에 묻히고 불빛만 남음. 가로등 없음(아포칼립스)
- 잔여 [미결]: 대형 건물 옥상 중앙 점광 어색함(외곽 배치는 메시 개편 필요), 주거지 건물 공백(GIS 전환), 버려진 차량, 산/바다, 컬러 팔레트 확정

## 11. 데이터/기술 [확정]

- 데이터는 공공(상가업소 CSV, OSM 도로·건물 → 추후 GIS건물통합정보), 렌더링은 자체
- 전 도시 확장 시 필수: **오프라인 전처리 + 청크 스트리밍 + 줌 LOD** (유일한 진짜 병목 = 전량 상주 방식. 별도 마일스톤으로)
- 최적화 실측 검산은 생략하고 진행 — 문제 발생 시 그때 타협
- 좌표계: 부산시청 앵커 로컬 미터 (GeoUtil)

## 12. 미결 질문 (우선순위순)

1. **장르: 스텔스 스캐빈저 vs 건슈팅** — M6 시야+추격 프로토 결과로 판단. (주의: 게임의 해자는 총맛이 아니라 실제 도시 데이터)
2. 구역 정화 확정 조건
3. 실내 진입 방식: 팝업 vs 직접 이동 (실내 씬 프로토로 비교)
4. 퍼즐 형태와 비중
5. 스트레스 게이지 도입 여부
6. 밤 특별 이벤트의 형태
7. BM (기존 메모 유지: 이동 스킵 판매 지양, 치장/편의 위주)
