## 0. v2에서 바뀐 것 (요약)

| 항목 | v2 | v3 |
|---|---|---|
| 게임의 위협 | 어두운 곳의 개별 좀비 | **도로망을 흐르는 좀비 무리(물량)** |
| 넓은 시야의 역할 | 성장 보상 | **행동의 근거** — 흐름을 읽어야 움직일 수 있음 |
| 참조점 | 타르코프/다크우드 | **스타크래프트 유즈맵, 뱀파이어 서바이버즈** + 미니 모토웨이(배치) |
| 루팅의 성격 | 물건 수집 | **위험을 뚫고 집어오기** (긴장이 시스템이 아닌 상황에서 나옴) |
| 카메라 | 고정 탑뷰 | **고고도 탑뷰 → 저고도 틸트** 전환 |

전환 계기: 스타크래프트 유즈맵('1억마리 저글링 막기')에서 착안. 실사 도시 데이터가
배경이 아니라 **게임판 자체**가 되는 구조 — 도로=진격로, 골목=병목, 대교/터널=요충지, 산/강=천연 방벽.

## 1. 핵심 플레이 루프 [확정]

**지도에서 흐름을 읽고 → 안전한 창(window)을 계산해 → 캐릭터로 침투해 필요한 걸 집고 → 흐름이 닫히기 전에 빠져나온다.**

- 광역 정보(드론/지도)가 곧 생존 정보. 관망과 캐릭터 조작이 인과로 이어짐
- 미니 모토웨이에서 가져올 것: **오브젝트 배치로 흐름을 바꾸는 것**만 (차 대신 좀비). 그 외 게임성은 미채택
- 소음 게이지 같은 인위적 긴장 장치 불필요 — 위험이 이미 화면에 흐르고 있음

## 2. 좀비 [확정]

- 뱀서/저글링 규격: **개체는 약하고 공격 모션 없음. 닿으면 피해.** 수가 늘고 둘러싸이면 위험 급증
- **단일 타입으로 시작** (워킹데드식). 변종은 한참 뒤 콘텐츠 확장
- 목적성 필요: 무작정 배회 = 움직이는 장애물 / 목표 보유 = **예측 가능한 흐름** → 플레이어 지능이 개입할 여지
  - 유력 후보: 갇히거나 도망치는 생존자에게 모여듦 → 생존자는 구조 대상이자 좀비 유인 미끼(이해충돌 발생)
- 시뮬레이션: 개체 단위 아님. **도로 세그먼트별 밀도 수치**로 흐르고, 화면엔 밀도 비례로 점을 뿌림 (물량감이 곧 재미이므로 성능이 설계의 일부)

## 3. 위협의 두 축 [유력]

| | 좀비 | 인간 악당 |
|---|---|---|
| 성격 | 지형처럼 흐르는 위협 | 생각하는 위협 |
| 행동 문법 | 밀도, 관성, 유인 | 원거리, 엄폐, 판단, 도주, 교섭 |
| 도입 시점 | M6 (지금) | 흐름 검증 후 2차 |

좀비 변종을 늘리는 것보다 인간 적을 추가하는 쪽이 플레이어 행동을 실제로 바꿈.
기존 기획의 비동기 유저 조우/다른 스캐빈저와도 연결됨.

## 4. 카메라 [유력]

- 고고도: 순수 탑뷰(90도) 유지 — 판단하는 층
- 저고도(캐릭터 조작): 스타크래프트식 틸트로 전환 — 몸으로 움직이는 층
- 각도는 **75~80도부터 시도**. 이유: 원근 투영이라 회전 보간만으로 구현되지만, 각도를 눕히면 extrude된 건물이 골목과 캐릭터를 가림
- 가림 해결 옵션(필요 시): ① 각도 완화 ② 카메라-캐릭터 사이 건물 반투명 처리 ③ 조작 중 주변 건물 높이 낮춤

## 5. 탑뷰 캐릭터 비주얼 [확정 방향]

탑뷰에서 '짜쳐 보이는' 것은 모델 퀄리티가 아니라 **실루엣과 움직임**의 문제.

- 플레이어: 방향성이 명확한 형태 + 밝은 색 / 좀비: 어두운 무채색 덩어리
- 그림자·접지 표시로 위치 명확화
- **무리의 흐름 자체가 비주얼의 본체** — 개체 하나는 점이어도 300마리가 골목에서 대로로 쏟아지는 모양은 그 자체로 볼거리

## 6. 유지되는 v2 결정 (변경 없음)

- 낮 = 긴장 / 밤 = 이완 리듬. 텍스트 선택지 최소화
- 아이템: 기능 원형 소수 + 가짓수 다수, 크래프팅 최소화/제거
- 안전구역 자유 지정(건물별 적성: 층수·출입구·수색률)
- 구역 정화: 파밍=수단, 소탕=마침표, **불빛=보상** (진행도를 도시의 빛으로 표현)
- 비동기 멀티: 구역별 확보도만 서버 공유
- 데이터는 공공, 렌더링은 자체 / 전 도시 확장 시 전처리+청크 스트리밍 필수
- 캐릭터 자원: 체력+스태미너 중심, 게이지 2~3개로 절제

## 7. 성격이 바뀐 v2 결정

- **층별 루팅**: 여전히 사용하되 자원 수급 수단으로 축소 가능. 층계 스태미너 규칙은 유지 후보
- **시야 원뿔/탐사 기억**: M6에서 일단 제외. 드론 기반 광역 정보가 먼저이므로 우선순위 하락
- **퍼즐 미니게임**: 우선순위 대폭 하락 (흐름 돌파가 긴장의 본체가 됨)
- **하루 사이클**: M6 이후로 미룸
